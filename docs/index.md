# 🔐 Cybersecurity Basics Notes

> *"Security is not a product, but a process."*
> — **Bruce Schneier**

Welcome to **Cybersecurity Basics Notes** — a structured, beginner-to-intermediate reference for **Cybersecurity**, covering everything from core concepts and networking fundamentals to web security, operating systems, and real-world attack & defense techniques.

---

## 🗺️ What's Inside

| # | Section | What You'll Learn |
|---|---------|-------------------|
| 01 | 🛡️ **Introduction to Cybersecurity** | Offensive vs defensive security, and careers in cyber |
| 02 | 🌐 **Network Fundamentals** | Networking basics, LAN, OSI model, packets, and frames |
| 03 | 💻 **Operating Systems** | Linux & Windows CLI, OS security concepts |
| 04 | 🌍 **Web Fundamentals** | How websites work, DNS, HTTP/HTTPS, and web request flow |
| 05 | ⚔️ **Attacks & Defenses** | CIA triad, cryptography, hacker mindset, and defensive strategies |

---

## 🚀 How to Use These Notes

!!! tip "New to cybersecurity?"
    Start with **Introduction to Cybersecurity → Network Fundamentals → Operating Systems** before moving into Web Fundamentals and Attacks & Defenses.

!!! info "Already have some background?"
    Jump straight to **Attacks & Defenses** or **Web Fundamentals** depending on what you're revising.

!!! warning "Keep in mind"
    Every topic includes real examples, diagrams, and practical context — read them carefully, don't just skim the content.

## 🛠️ Run Locally

```bash
# Clone the repo
git clone https://github.com/your-username/Cybersecurity-Basics.git
cd Cybersecurity-Basics

# Create virtual environment
python -m venv venv
source venv/bin/activate   # Mac/Linux
venv\Scripts\activate      # Windows

# Install dependencies
pip install mkdocs mkdocs-material

# Serve locally
mkdocs serve
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000) in your browser.
